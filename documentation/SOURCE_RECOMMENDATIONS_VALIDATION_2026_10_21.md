# Exact-topic source recommendations: Cloudflare validation, 2026-10-21

Target: `distilled-news-joud`. These are pre-deployment network checks of the final recommendation and assessment modules in a temporary, authenticated Cloudflare Worker in the same account, with the same compatibility flags and model configuration. No database binding or user feeds were used by the probe.

The user requires the actual topic and any specified geography. Related industry sources are rejected. The coconut test input was `News about coconuts in Australia`, not a broader agriculture request.

The fictional negative case requested council decisions from an imaginary underwater city on Jupiter. It correctly returned no sources. All returned sources in the real-topic cases were independently re-read and reassessed using the same `assessSources` implementation used by source selection. The combined test action has a longer harness deadline than an individual recommendation because it includes both actions.

## Coconut case

Verified publisher-filtered feeds:
- `rss: https://retailworldmagazine.com.au/?s=coconut&feed=rss2`
- `rss: https://www.australianmanufacturing.com.au/?s=coconut&feed=rss2`
- `rss: https://insidefmcg.com.au/?s=coconut&feed=rss2`

The supporting items cover Australian coconut-water businesses and coconut-product launches. FreshPlaza and general agriculture feeds were rejected for lack of direct topic evidence. Search feeds return real RSS items; reflected query titles do not count as evidence. Displayed excerpts are copied by the server from cited fetched items, not generated by the model.

## Implementation and checks

- Discovery uses a publisher capability catalog, then at most one bounded fallback web search. Catalog entries are candidates, never approval.
- Supported WordPress search RSS endpoints are verified before use; the approved URL retains its topic query for subsequent collection.
- Direct topical relevance, geographic constraints, suspicious content and valid fetched-article citation IDs are checked using structured model output.
- Results are deduplicated by publisher hostname. Explicitly stale dated feeds are excluded.
- Google News is excluded from Joud recommendations because it blocks the deployment. Existing approved sources are not silently switched.
- Recommendation network budget: 20 seconds total, 8 seconds per call; evidence bodies remain capped at 512 KB.
- 59 targeted Worker tests and 8 frontend tests passed. Worker/web typechecks, web build and Joud dry-run packaging passed.

These tests cover the listed inputs and live responses. They do not prove that multiple sources exist for every conceivable topic, guarantee future publisher availability or measure production-browser interaction. The authenticated application route and database source creation were not exercised by the isolated probe; UI behavior was covered by frontend tests. No new source family, migration, private execution service, paid collection grant or shared-contract change was introduced.
