## Resulting workflow

New ordinary V3 snapshots freeze `editorSourcePolicy=all-supporting-sources-v1`, `editorAccountingPolicy=complete-source-decisions-v2` and `citationCoverage=false`. The editor groups the same occurrence/decision/statement into one item and lists every supporting article label, including translations and shorter reports. Partial-chunk editors propose grounded short supporting drafts for later consolidation, rather than silently discarding a fragment that a fuller report can complete. They must not expand names, roles, actions or locations beyond the source text.

Consolidation keeps every corresponding draft index and takes the deterministic union of their citations. It can add a supporting citation without adding filler text. The existing factual-verification call sees the cited source bodies and explicitly checks each supports the central development; unrelated citations must not be approved. Targeted repair retains the source references. No separate full-input citation-audit call is made for this new policy.

Concise omission categories, including `off-topic`, are accepted under accounting v2. Every source must still be selected or explicitly omitted; missing, blank, conflicting or fabricated-reference decisions use the existing correction path and retain unresolved evidence if unsuccessful. Per-source audit trails remain private operational records, separate from published payloads.

Legacy frozen snapshots keep their original policy, requests, paid operation IDs and separate citation audit. Accounting v1 keeps its existing stricter reason contract. The staging readiness relay and verified-edition artifact flags remain enabled. Production configuration is unchanged.
