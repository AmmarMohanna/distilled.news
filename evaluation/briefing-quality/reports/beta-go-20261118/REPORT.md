2. Material-recovery coverage wrongly demanded other developments from a long source article, including a different speaker's statements. The V2 packet now explicitly identifies the original selected headline/body as scope only, never factual evidence. It still requires source support and retention of material groups/actions already represented or necessary to avoid misleading meaning. Original aggregate references still require preserving their supported constituent groups.
3. Even with explicit scope, real model coverage judgments falsely called an otherwise identical title correction a material omission. Code now proves a narrow **identity-only preservation** case: the first repair-history draft must match the current full headline/body exactly after a source-bound role replacement or an unambiguous unsupported given-name removal. Roles require an `INDEPENDENT_ROLE_MISMATCH` finding and an exact source phrase tying the new role to the original actor. A source-established full name may become a suffix/surname, never gain tokens. Given-name removal requires the existing `PERSON_NAME_NOT_SOURCE_BOUND` finding, one matching source-established suffix, and all other words unchanged. Any other edit, missing material group, changed count, unsupported title, unrelated actor or unmatched wording still goes through the source-grounded coverage model. This proves preservation of reader material, not original selection completeness or factual truth. Factual approval still precedes this gate.
4. The existing V2 repair slots now explicitly retain the original supported story body and make the demonstrated identity correction without optional recompression. No repair rounds or new model family were added. Verification failures and uncertain payments still propagate honestly; healthy siblings remain publishable.

The V4 editor and generation options are unchanged. New-policy fingerprints, durable paid operations, private/public access, accounting, recovery and deployed evaluators are preserved. No deployment, merge, production data change or flag activation occurred.
