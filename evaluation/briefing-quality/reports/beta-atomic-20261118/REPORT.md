# Atomic assertions and exact identity repair

18 November 2026. Follow-up to the preserved negative French probe. **Code qualification passes the targeted release regressions; live staging qualification is pending exact-head CI and the new bounded attempt.** This is not unrestricted public-beta certification.

## Changes grounded in observed failures

V2 separated people/roles but mostly reviewed other assertions as whole headlines/bodies. It accepted “unanimement” for a source establishing only overwhelming agreement. V3 adds exact token-span atomic assertions to the **existing reader-only inventory call**, separately checking scope, uncertainty, quantities, timing and actions alongside complete reader text. Source-only identity extraction remains blind. No names, office holders, languages' qualifier word lists or source facts are hard-coded. Required fields, exact spans, negative preservation, citation checks and per-item isolation remain enforced. New input fingerprints select `source-bound-claims-v3`; unmarked/v1/v2 requests retain their behavior and reader prompt bytes.

An intermediate run falsely identified a French grammatical determiner as a personal name. Its response and false positive remain recorded. The V3 extraction contract now explicitly distinguishes proper names from unnamed role references; role-only claims still receive factual checks. No unsupported identity is silently removed by a word filter.

A complete engine replay exposed the generative repair removing an independently supported role while correcting an invented given name. The coverage gate correctly withheld that altered story. V3 now makes **only narrowly source-bound identity edits** in code when every received issue is a recognized identity finding, the replacement is unique and grounded in attached evidence, and the named span actually occurs. It can shorten an unsupported full name to an evidenced suffix or replace a source-contradicted role for the same actor. Every other character is preserved; other/ambiguous issues retain normal repair. The edited text is factually re-verified. The material-coverage shortcut proves exact preservation only, never truth or overall source recall. V2 is unchanged.
