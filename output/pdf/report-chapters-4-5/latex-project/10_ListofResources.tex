\section{Economic and Resource Planning}
Our economic accounting has three classes: (1) confirmed settled provider charges, (2) reserved/unknown exposure not yet a confirmed invoice, and (3) shared infrastructure cost, which requires provider billing data and allocation. We will never add a conservative reservation to a settled charge and label the sum a single actual bill. In isolated tests, the 20-article V3 replay cost \$0.0723856 in confirmed model inference, while a different larger run cost \$0.2605756; these are \emph{per-case inference charges}, not subscriptions, cost per active user, or full service total cost \cite{v3twenty,v3overnight}.

For final evaluation, each run manifest will identify preapproved maximum exposure, provider/model, source/API usage, number of attempts, original billable operation keys, exact settled amounts, unresolved holds, and allocation for shared collection. The team will use finite per-experiment approvals and a separate project expenditure ledger. No arbitrary bill-of-materials dollar total is asserted where the deployment invoices have not been examined.

\section{Key Skills and Training Needs}
The team has working experience with TypeScript, React, API services, CI, SQL persistence, automated testing and bounded AI workflows. Remaining learning/application focuses are independent annotation methodology and inter-rater agreement; confidence intervals and paired statistics; live load/fault injection; Cloudflare billing and tracing; threat modelling; and WCAG 2.2 AA manual accessibility audit. These are listed as planned skills, not as limitations imposed on the product itself.
