# Governance

Distilled.news is maintained by the people with merge and production-release
authority in the repository and Cloudflare account.

Routine code and documentation changes require review and passing CI. Changes
to authentication, public visibility, retention, paid-provider controls,
database migrations, legal terms, or production infrastructure require an
explicit maintainer approval. Production releases also require the protected
GitHub environment and the release readiness gates.

Security incidents may justify an emergency fix with abbreviated review. The
incident commander must record the reason, affected commit, validation, and
follow-up work. Emergency access does not waive post-incident review.

Project direction is documented in the repository. Material product changes
should be proposed in an issue or design note before implementation. The
maintainers make the final decision after considering users, operators,
contributors, security, cost, and legal obligations.

Maintainers may be added or removed by consensus of current maintainers.
Access must follow least privilege and be removed promptly when no longer needed.
